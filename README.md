# shotkey

ホットキーで撮って、指定フォルダに保存するだけの、Windows 用スクリーンショットアプリ。
撮るのが目的なので、編集はしない (編集は [Lookover](https://github.com/fixtan/lookover) でやる)。

## 撮れるもの

| ホットキー (初期値) | 撮るもの |
|---|---|
| `Ctrl+Alt+1` | デスクトップ全体 (全モニタをつないだ 1 枚) |
| `Ctrl+Alt+2` | マウスのあるモニタ |
| `Ctrl+Alt+3` | いま手前にあるウィンドウ (影を含まない、見えている枠だけ) |
| `Ctrl+Alt+4` | 範囲を選ぶ (自由サイズ) |
| `Ctrl+Alt+5` | タイマー: 数秒待ってから、そのとき**手前にあるウィンドウ**を撮る |
| `Ctrl+Alt+6` | タイマー: 数秒待ってから、そのときマウスのあるモニタを撮る |
| `Ctrl+Alt+7` | タイマー: 数秒待ってから、デスクトップ全体を撮る |

- ホットキーは、設定画面で変えられる。ほかのアプリと重なっていたら、設定画面に出る。
- **範囲は、先に画面を固めてから選ぶ。** だから、右クリックメニューのような「撮ろうとすると消えるもの」も撮れる。
- 保存先とファイル名は設定で決める。連番は「保存先にある一番大きい番号 + 1」なので、消してもずれない。
- PNG / JPEG。撮ったらクリップボードにも入れる設定もある。
- 窓を閉じてもトレイに残る。終わるのは、トレイの「終了」。

## 効果音

撮影時のシャッター音 (`src-tauri/assets/shutter.wav`) は、[効果音ラボ](https://soundeffect-lab.info/) の素材を、
WAV に変換して、前後の無音を削り、音量をそろえたものです。
効果音ラボの素材は、商用利用も無料で、クレジット表記も要りません。
アプリの操作音として組み込むことは、規約上、再配布に当たりません。
音は、設定で、鳴らす・鳴らさないを選べます (初期値は鳴らす)。

## 動かす

```
npm install
npm run tauri dev
```

Rust と、WebView2 (Windows 11 なら最初から入っている) が要る。配布用は `npm run tauri build`。
タグ `v*` を push すると、GitHub Actions が Windows のインストーラーを作って、下書きのリリースに置く。

## いまできないこと

- 範囲選択は、**1 つのモニタの中だけ**。モニタをまたぐ範囲は選べない (またぎたいときは、デスクトップ全体で撮って切る)
- ウィンドウ撮影は、固めた画面から切り出すので、**ほかのウィンドウが重なっていたら、重なったまま**写る
- 範囲を選んだあとの、動かす・大きさを変える
- 動画 (静止画が安定してから)
- 管理者権限のウィンドウ (タスクマネージャーなど) が手前にあるとき、ホットキーが効かないことがある
- DRM のかかった映像は、真っ黒に写る

## 作り

`core/` は、Windows に依存しない部分 (座標計算・連番・画素の切り出し)。`cargo test -p shotkey-core` で試験できる。
`src-tauri/` が、撮影・ホットキー・トレイ・重ね画面。`src/` が、設定画面と重ね画面 (素の HTML / JS)。
`node test/ui.mjs` で、画面側を、Tauri を模して試験できる。
